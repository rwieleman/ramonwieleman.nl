# ramonwieleman.nl

A small static site: no build step, no framework.

- `index.html`: about Ramon
- `blog/`: writing; one folder per piece
- `assets/`: the style sheet, pictures and screenshots
- `game/`: Ramon's Rampage, built from `../ramons-rampage` with `npm run build:web` there

To look at it on this computer, serve this folder with any static file server.
To publish it, upload the whole folder as it is.
